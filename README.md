🎵 Music Instrument Recognition System

📌 Project Overview

This project is an AI-based Music Instrument Recognition System developed using Python and Streamlit.
The system analyzes uploaded audio files and predicts the musical instrument using audio feature extraction and machine learning techniques.


🚀 Features

🎧 Audio Upload (.wav / .mp3)
🎨 Mel-Spectrogram Visualization
📊 Multi-Instrument Probability Analysis
🎵 Final Instrument Prediction
📈 Confidence Score Display
📄 JSON Report Export
📑 PDF Report Export
🌐 Streamlit Web Interface


🧠 Working Architecture

1. User uploads audio file
2. Audio is processed using Librosa
3. Mel-Spectrogram features are extracted
4. Model predicts instrument class
5. Results displayed with confidence
6. Report generated (JSON / PDF)


🛠 Technologies Used

Python
Streamlit
NumPy
Librosa
Matplotlib
ReportLab
